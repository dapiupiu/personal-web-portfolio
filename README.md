## Featured Projects

### EduPredict AI — Early Warning Education System
Capstone project directing a 6-member team to build a student academic risk prediction system. Achieved 91.23% accuracy and 0.0154 MAE using TensorFlow, with domain-driven feature engineering and clamping logic to safeguard model robustness against out-of-distribution inputs.

### Road Infrastructure Sentiment Analysis via Weak Supervision
First-author research on an automated NLP classification pipeline for public infrastructure complaints across 60+ regional news sources, achieving 70.93% accuracy and 0.86 precision using rule-based lexicon scoring and SMOTE.

### Computer Laboratory Assistant Recruitment System
Academic prototype for a centralized web recruitment platform, including system workflow architecture, UML modeling, and a relational database design that reduced candidate evaluation turnaround by 66.67%.
